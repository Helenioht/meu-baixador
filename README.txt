COMO COLOCAR NO AR NO RENDER

1. Crie um repositório no GitHub e envie estes 4 arquivos:
   index.html
   app.py
   requirements.txt
   Dockerfile

2. No Render, crie New > Web Service e conecte o repositório.
3. Escolha o plano Free.
4. O Render detectará o Dockerfile.
5. Depois do deploy, abra o endereço *.onrender.com.

O serviço usa yt-dlp e ffmpeg. O armazenamento local do serviço gratuito é temporário; os arquivos baixados são para entrega imediata.

Use apenas para vídeos cujo download seja permitido por você e pelos termos do serviço de origem.
